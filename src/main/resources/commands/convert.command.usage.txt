mog convert --runid=<runid> [--subdir=<sub-directory>] (*)
cnvj --runid=<runid> [--subdir=<sub-directory>] (*)

Runs the conversion program for the current project directory.

    --runid              :: The runid for the conversion run
    --subdir (optional)  :: A sub-directory used to identify correct input folder and output folder
    --help               :: displays this


* - Must be run from a subdirectory within the project folder (i.e. bin, sysin, src)
