mog source --env=<database env> [--subdir=<sub-directory>] (*)
cnvs --env=<database env> [--subdir=<sub-directory>] (*)

Source the data from the source environment for the current project directory.

    --env                :: The target database environment
    --subdir (optional)  :: A sub-directory used to identify correct input folder and output folder
    --help               :: displays this


* - Must be run from a subdirectory within the project folder (i.e. bin, sysin, src)
